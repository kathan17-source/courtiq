# Feature definitions

Core pre-match features:

- Surface-specific Elo difference
- Overall Elo difference
- Recent-form Elo difference
- Serve hold-rate difference
- Return break-rate difference
- First-serve points-won difference
- Second-serve points-won difference
- Break-point conversion/save difference
- Head-to-head surface-adjusted record
- Rest days and fatigue proxy
- Tournament round and best-of format

Point-by-point features:

- Server
- Current score state
- Break-point state
- Rally length
- Serve outcome
- Winner / forced error / unforced error
- Momentum state estimate
